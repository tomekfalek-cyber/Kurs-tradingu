# Kurs Analizy Technicznej — Pełne Szkolenie

Autorski, kompletny kurs analizy technicznej rynków finansowych po polsku, w formie samodzielnej strony HTML.

## Zawartość

53 rozdziały obejmujących m.in.:
- Teorię Dowa i fundamenty AT
- Rodzaje wykresów, trend, wsparcie i opór
- Pełny katalog formacji świecowych i cenowych
- Zniesienia Fibonacciego, średnie kroczące, wstęgi Bollingera
- Oscylatory: RSI, MACD, Stochastic, ADX
- Fale Elliotta, metodę Wyckoffa, Ichimoku Kinko Hyo
- Wykresy Point & Figure, analizę międzyrynkową, cykle, luki cenowe
- Zarządzanie ryzykiem, Kelly Criterion, plan tradingowy, dziennik transakcji, backtesting

## Jak korzystać

Otwórz `index.html` w dowolnej przeglądarce — działa offline, bez instalacji.

Jeśli włączysz GitHub Pages dla tego repozytorium (Settings → Pages → branch `main`, folder `/root`), kurs będzie dostępny pod publicznym adresem `https://<twoj-login>.github.io/<nazwa-repo>/`.

## Zastrzeżenie

Materiał ma charakter edukacyjny — autorskie opracowanie ogólnodostępnych, klasycznych zasad analizy technicznej. Nie stanowi rekomendacji inwestycyjnej. Handel instrumentami finansowymi wiąże się z ryzykiem utraty kapitału.
